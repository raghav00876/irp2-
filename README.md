### Assignment Overview
This repository contains solutions to four DSA coding problems implemented using Python.

### Problems Included

**1. Reverse Word Order**
- File: `p1_reverse_words.py`
- Reverses the order of words in a given sentence.
- Example:
  - Input: `I love coding.`
  - Output: `coding love I.`

**2. Binary Search**
- File: `p2_binary_search.py`
- Searches for a target element in a sorted array using binary search.
- No built-in search function is used.
- Example:
  - Input:
    ```text
    5
    1 3 5 7 9
    7
    ```
  - Output: `3`

**3. Digit Sum Using Recursion**
- File: `p3_digit_sum.py`
- Calculates the sum of digits using recursion only.
- Example:
  - Input: `9875`
  - Output: `29`

**4. Pair Count**
- File: `p4_pair_count.py`
- Counts pairs of integers whose sum equals the given target k.
- Example:
  - Input:
    ```text
    5 6
    1 5 2 4 3
    ```
  - Output: `2`
